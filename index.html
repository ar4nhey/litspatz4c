Aframe - VR Scenes

Aframe is a web framework for building 3D experiences, that extends HTML syntax with the aframe library to create 3D worlds with HTML tags and entity-components like GLB-files creates with OpenSource Blender The 3D models can be viewed with VR-headset, mobile phone and desktop PC. The following use cases in Aframe take equirectangular images and use them in a VR scene as 360 degree sky image.
