## Multi Markers AR.js
The term multi-marker in AR.js means using more than one marker at a time to define the spatial position of an AR object. 
In contrast to a single square marker (e.g Hiro marker)  multi-markers acting as one larger marker that define all together a spatial position.
This can be used 
* when you turn around and loose one marker in the camera view,
* others markers can take over to provide positioning information.
 This allows to place multiple markers in the 3D space and a single marker is sufficient to detect the position of the AR object.
