## README - Animated Objects 
This folder `/move360` contains all HTML files that contain moved objects in the 3D coordinate system.
* **Filetype (AR.js/Aframe):** If the filename starts with a leading `ar_` then the file uses `AR.js` for Augmented Reality (see [https://ar-js-org.github.io/AR.js-Docs/](https://ar-js-org.github.io/AR.js-Docs/) )
* **AR (Used Marker):** All files for Augmented Reality using `AR.js` end with the marker name (e.g. `_hiro` or `_kanji` see [PDF-Marker](https://niebert.github.io/JSON3D4Aframe/pdf/marker_hiro_kanji_printout.pdf)
