## Images and Marker
This image folder contains:
* Markers in the `marker/` subfolder - see also <https://github.com/AR-js-org/AR.js/tree/master/data/images> for marker images and GitHub repository [jsartoolkit5](https://github.com/artoolkitx/jsartoolkit5)
* `LitSpatzLogo.jpg` Logo of the project - copyright by Dr. Nora Heyne (University of Bamberg)
* `icons4menu` [GitHub repository](https://github.com/niebert/icons4menu) with licensing info for the icons. A few icons are used here for the project. The file `json4icons.json` contains all licensing info for all icons and reference url to the icon.
