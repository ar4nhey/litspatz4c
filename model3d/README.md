## directory information
In this directory you find 
* all 3d-models as glb-files,
* and models created with [JSON3D4Aframe](https://niebert.github.io/JSON3D4Aframe) (e.g. the [green Wizzard hat](wizzard_hat_json3d4aframe.json) as JSON file). The JSON files can be loaded and modified in [JSON3D4Aframe](https://niebert.github.io/JSON3D4Aframe).
