## Comment of directory
In this directory you find all used javascript files for the LitSpatz4C. Moving objects is performed with 
* [`aframe-object-mover.js`](./js/aframe-object-mover.js) for [Aframe](https://aframe.io)
* [`ar-object-mover.js`](./js/ar-object-mover.js) for [AR.js]([https://ar-js-org.github.io/AR.js-Docs/)
